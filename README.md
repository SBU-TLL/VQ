# VQ (Video Quiz) Player

## Branch Summary
This branch adds accessibility and keyboard improvements across the VQ app, plus local development setup updates.

### Highlights
- Improved keyboard navigation for quiz interactions and editor flows
- Converted interactive controls to proper button elements
- Added focus rings and dynamic ARIA roles for screen-reader support
- Updated video/question layout and player feedback behavior
- Fixed folder management and tab/enter loop issues in the editor
- Added DDEV configuration for local development with a Shibboleth mock
- Cleaned up stray macOS metadata files and project artifacts

### Notes
This branch was derived from the `abi` branch and includes the local DDEV setup plus UI/accessibility work from the `zijun` branch.
